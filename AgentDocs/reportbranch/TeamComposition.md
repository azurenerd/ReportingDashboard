# Team Composition

**Project:** A polished 3D animated project reporting dashboard using Node.js/Express and Three.js/React Three Fiber for executive presentations, visualizing mock project data with WebGL-powered interactive scenes.

## Rationale
This project demands specialized 3D graphics and frontend animation expertise (Three.js, React Three Fiber, GSAP, WebGL post-processing) that generic Software Engineers typically lack. A dedicated 3D Frontend Engineer handles the complex scene composition, shaders, and animations, while a Backend/API Engineer builds the Express mock data layer. The built-in Architect is critical for designing the hybrid 3D+HTML rendering architecture and state management patterns.
